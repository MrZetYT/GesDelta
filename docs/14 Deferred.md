# 14. Отложено на конец

Реестр того, что сознательно не делаем до сквозной демонстрации (цель: середина декабря 2026), и того, что для этого заложено заранее. Решение: D-061, D-062. Порядок отсечения: D-050 плюс дополнения D-061.

Правило: отложенное возвращается добавлением (новый класс, строка в DI или конфиге), а не переделкой. Для этого сейчас закладываем швы (раздел 2). Шов стоит почти ничего, а без него возврат превращается в переписывание.

## 2. Швы: чек-лист «закладываем сейчас»

Пять правил. Каждое проверяется при ревью соответствующей задачи.

- [ ] **Keyed DI по `SourceType`.** В Collector нет `if (type == Rss)`. Реализации регистрируются по ключу типа (05, разд. 7, п. 3).
- [ ] **`Chain` массивом.** В конфиге цепочка моделей это массив, даже из одного элемента (07, разд. 1). Код идёт по массиву, а не читает одиночное поле.
- [ ] **Всё через `IMonitoringService`.** CLI-команды `setup`, `run`, `ask`, `status`, `changes` вызывают фасад. Агентов и DbContext напрямую из `Cli` не трогаем (02, правила). Пока команды `collect` и `detect` диагностические, их можно оставить как исключение (D-049).
- [ ] **`TimeProvider`.** Время в планировщике и в QA берётся из `TimeProvider`, не из `DateTime.UtcNow` (11, разд. 5).
- [ ] **Промпт QA шага 1 сразу на четыре типа.** `qa_parse.md` отдаёт `WhatChanged | WhenFirst | Explain | Unknown` (08, разд. 2). Меняется только то, что код делает с `Explain`.

## 3. Не режем (возврат дорогой)

Это не откладывается ни при какой нехватке времени, потому что вставлять задним числом дороже, чем сделать сразу.

|Что|Почему нельзя отложить|
|---|---|
|База для diff: снимок последнего Change (D-056)|Позже придётся переписывать данные, тесты и Detector|
|Финальная транзакция: `done_at`, закрытие Run (D-055)|На ней держатся журнал, `sinceLastRun` и атомарность|
|Critic (код)|Встроен в петлю Analyzer. Задним числом означает переделку конвейера|
|Трассы LLM (11, разд. 2)|Без них отладка «агент вернул чушь» превращается в гадание. Задним числом не нужны|
|Detector целиком (хэш, diff, пороги, бюджет)|Граница код/LLM (D-009), запуск без изменений стоит 0 токенов|
|Сценарии A-C из 11|Закрывают критерии готовности 1-4 из 00|
